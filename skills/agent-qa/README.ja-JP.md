# agent-qa

[English](./README.md) · [中文](./README.zh-CN.md) · [日本語](./README.ja-JP.md)

vostride の [agent-qa](https://github.com/vostride/agent-qa) によるアプリケーション QA。高度な memidex メモリエンジンと自己改善機能を備え、自然言語で Web、Android、iOS をテストします。

## 使い方

agent-qa を設定済みのプロジェクトで、コーディングエージェントに依頼します。

> 選択した agent-qa の実行記録をレビューしてください。要約、関連ステップの証拠、知識の出所を確認し、テストやメモリを変更せずに原因と次の手順を説明してください。

実行を依頼する場合：

> 開発ビルドに対して選択した agent-qa 回帰テストを実行し、記録された判定とその根拠を報告してください。

このスキルは依頼に応じた手順を選び、実行前に設定を検証し、必要な証拠を読み取ります。過去に使われた知識と現在の状態を区別し、既存の本番環境保護と元の実行判定を維持します。

## 要件と制限

- shell、Node.js 24 以降、CLI がインストールされた設定済みの agent-qa プロジェクトが必要です。
- 実際の実行には対象アプリと設定済みのプロバイダーも必要です。モデル、ブラウザー、デバイスの利用料が別途発生する場合があります。
- 0.1.0 は実験的な統合です。形式の互換性は、記載された全エージェント環境での実行検証を意味しません。
- 証拠がないことは成功を意味しません。スクリーンショットやネットワークの内容は共有前に確認してください。個人情報は自動でマスクされません。

このスキルの独自の手順説明には、このコレクションのライセンスが適用されます。外部の agent-qa ランタイムは別途 **FSL-1.1-ALv2** でライセンスされており、同梱されていません。
