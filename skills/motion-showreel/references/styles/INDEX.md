# 风格库

每个风格一个文件，只写**这种风格不变的规则**：本质、材质、配色、字体、运动、画面怎么活、镜头语法、声音调色板、原生手法、坑。**不写任何具体的故事、分镜和时间线**，这些从用户的主题和 `formats.md` 的用途里来。

## 怎么用（先读这一段）

- **风格库是起点，不是选择题。**它的作用是给你一套具体、可执行的约束，免得落进 AI 的默认风格；它不是天花板。下面三种用法同样正当：
  1. **直接用**：选一个风格，规则照着守，内容全部为主题重新设计。
  2. **改造**：以一个风格为底，替换其中一两条（比如把配色换成品牌色、把运动换成步进），并在 brief 里写明改了什么。
  3. **自定义**：主题需要的风格不在库里时，按 `_template.md` 现写一份规则放进 brief。对标作品、媒介特性、品牌资产都可以作为依据。
- **只读你选中的那 1–2 个文件**，不要把整个风格库都读进上下文。
- **认得出就够了，不用全上**：每个风格文件都列了 8–12 个「辨识信号」和一份「最俗的版本」。按主题挑 2–3 个信号，至少一个不在俗套里；同一个风格做第二支片子时，换一组信号。配色里的色值都是示例，按推导规则从主题和品牌重新配。
- 风格规则和内容要分开：换一个主题时规则保留，故事、结构、镜头、开场和结尾全部重新想，**不要把上一支片子换个文案再交一次**。每个风格文件末尾的「变化空间」就是用来提醒这一点的。

## 用户没指定风格时：挑 3 个方向

在第 3 步风格帧确认时，给用户 3 个**拉开差距**的方向，每个方向配一张用真代码渲出来的关键帧：
- **A 贴合**：最贴近主题、品牌或素材的风格。
- **B 换语言**：同样的内容换一种画面语言，从**另一个分组**里选。
- **C 大胆**：自定义风格，或者两种风格混搭，或者用一个结构上很大胆的讲法。至少要有一个方向不是库里现成的。

三个方向不能来自同一个分组，也不能只是换配色。

## 混搭

- **一主一辅**：一个风格定全片的系统（配色、字体、运动性格），另一个只出现在一个段落或者一个签名时刻里。
- **按段落切换媒介**：年代跨度大的主题，可以每一段换一种媒介（参见 `mixed-media-era.md`），但要有一根贯穿全片的线：同一个主角、同一种转场语法，或者同一首配乐。
- 混搭时在 brief 里写清楚哪些规则以哪个风格为准；有冲突时以主风格为准。

## 新增风格

复制 `_template.md`，以 `<slug>.md` 命名，写完后在上面的目录表里加一行。写规则的时候问自己：换三个完全不同的主题，这些规则还都成立吗？只适用于某一个主题的内容，不应该写进风格文件。
