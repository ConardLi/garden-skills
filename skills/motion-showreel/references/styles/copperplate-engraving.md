# 铜版雕刻（copperplate-engraving）

> 细密的刻线沿着形体转折，疏密之间显出明暗；纸上的图谱可以被放大、标注，也可以一层层印出来。
> 参照（只学语法）：铜版雕刻的排线与刻刀线、古典博物图谱、手工设色版画。不照搬具体图版、构图、标本姿态和装饰边框。
> 借鉴方向：[lemo-opuscar 的 Copperplate Engraving](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/engraving/STYLE.md)，按本库结构重新整理，技术实现由 Agent 按主题探索。

## 本质 / 不是什么

- 本质：**用刻线的疏密和粗细表现明暗**。线条顺着物体表面弯曲，暗部增加交叉排线，亮部露出纸色；刻刀入版、加深、抬起，留下两端细、中间较厚的线。画面的体积从这些线里长出来。
- 不是：黑底白刀痕的木刻、松散的钢笔速写，也不是照片套棕褐色滤镜。纸张做旧和古典边框只是可选装饰，不能替代随形排线。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 随形排线 | 线条沿着叶面、器物或地势弯曲，疏处亮、密处暗 | 形体、工艺、自然 |
| 交叉排线 | 暗部叠入另一组方向不同的细线，逐渐显出体积 | 深度、揭示、变化 |
| 刻刀线 | 一条线由细变粗再收尖，转折处有力度变化 | 精密、手艺、力量 |
| 印版压痕 | 图版边缘留下压入纸面的浅痕，斜光下才明显 | 出版、收藏、制作过程 |
| 放大细节圈 | 局部被放大到旁边的圆框里，引线仍指向原位置 | 微观、结构、产品细节 |
| 编号与引线 | 小编号、细引线和短注释围绕主体排列 | 讲解、分类、组成 |
| 透明手工淡彩 | 少量颜色铺在线刻图上，底下的刻线仍然清楚 | 重点、状态、季节 |
| 试印层次 | 同一形体从轮廓、浅排线到完整暗部逐次显现 | 过程、积累、完善 |
| 局部修版 | 一小块旧线被磨去，再刻出新的结构 | 修订、前后对比、演变 |
| 图谱题签 | 衬线标题、斜体名称和留白边注组成清楚的阅读顺序 | 博物、文化、知识 |

规则：

- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里。
- 信号从主题里选，不按顺序全上。
- 随形排线和刻线的粗细变化始终成立；放大圈、题签、压痕和淡彩按内容取舍，不必把每支片子都做成旧书图版。

## 这个风格最俗的版本

- 画面：泛黄纸面正中一只昆虫，周围一圈拉丁标签，羽毛笔划过，最后套上繁复花边。
- 声音：羽管键琴从头弹到尾，每根线出现都配一下刮擦声。
- brief 的 style 一栏写明这支片子翻掉了哪几条，或者为什么刻意保留（比如用户要的就是经典版）。保留时，把变化放在观察角度、细节选择或线条形成的过程上。

## 适配

- 用途：工艺与文化宣传片、博物讲解、产品细节展示、片头、Logo 演绎。
- 内容：自然、建筑、地理、精密器物、知识出版；现代产品和虚构世界也可以用这种画法。
- 不适合：密集 UI 操作演示、连续高速卡点，或小屏幕上需要同时阅读大量标签的内容。

## 技术路线

- **平面线刻**：Canvas 2D 或 SVG 都可以作为起点。可以从主题的矢量轮廓出发，探索按区域安排排线方向、随明暗改变线距和粗细，再用遮罩控制显现的办法。
- **路径处理**：曲线整理、求交和形状裁切可考虑 Paper.js；偏生成式绘图也可用 p5.js。它们提供绘图能力，刻线的组织方式仍需按本片的形体设计。
- **大面积排线与纸墨质感**：需要处理很多线或复杂遮罩时，可探索 WebGL，或借助 PixiJS 组织纹理、遮罩与自定义滤镜。纸、刻线、可选淡彩分层处理，先确认线刻本身成立，再加材质。
- **铜版特写**：只有内容确实需要展示印版、压痕或斜光时，再考虑 Three.js 的材质与灯光；以平面图谱为主的片子可以全程使用 2D。
- 遵守现有的确定性渲染约定：同一时刻能独立还原线条的显现程度，纸纹和刻线扰动固定种子。先检查最终尺寸下的细线，再决定是否提高采样分辨率；运动模糊与额外颗粒从轻，避免抹掉排线。

以上是候选方向，按主题和复杂度选用；具体的排线算法、图层组织和动画实现由 Agent 探索。

## 材质与渲染

- 工艺依据：刻刀在铜版上留下凹槽，凹槽存墨，压印后成为纸上的线。画面重点是线的力度和排布；铜的金属反光只属于印版，不能带到印好的纸上。
- 排线贴着形体走：圆面有弧度，平面有方向，前后遮挡处线条自然截止。整屏覆盖同一角度的斜线会抹平结构。
- 暗部逐步加密或交叉，亮部保留纸色。细节多的主体要留出明暗层次，别把所有区域都填满。
- 纸面干净、略有纤维和浅压痕；纸纹随纸移动，刻线随物体移动。前景主体与背景遵守同样的线刻规则。
- 淡彩可轻微越过轮廓，边缘偶有水痕，但保持透明，让刻线承担结构和明暗。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 暖纸黑墨：纸 `#F2EBDD` / 墨 `#27231F` / 少量赭色淡彩 `#B88952`。
- 冷白蓝墨：纸 `#F3F5F2` / 墨 `#293D4D` / 少量灰绿淡彩 `#91A996`。
- 中性纸与品牌色：纸 `#EEECE5` / 墨 `#30302E` / 一处朱红淡彩 `#B85D51`。
- 推导：先选能衬清细线的纸色，再从主题或品牌色里取足够深的单一墨色；强调色用于正在讲的局部。明暗主要靠线条，淡彩保持透明，纯单色也成立。

## 字体

英文标题可选 EB Garamond、Libre Baskerville，短名称可用同家族斜体；中文可选思源宋体。优先使用 OFL 字体并自托管。标题比标签明显大一档，引线与注释分开留空，不为了仿古把字号压小。文字较多时保持字面清晰，把线刻质感留给插图。

## 运动

- 可以按轮廓、浅排线、交叉暗部逐层显现，也可以直接从完整图像开始，逐个放大重点。顺序服务于讲述，不必每次重演制版过程。
- 线条显现有稳定的推进感，局部收笔略慢；大幅弹性回弹会破坏刻刀的力度感。
- 主体要运动时，排线跟随形体变化，避免像一张固定网纹盖在动图上。选择细小、清楚的动作，复杂动作先简化。

## 画面怎么活

- 图谱本身以静为主，镜头停住时留给观众阅读；刻线和纸纹不持续抖动。
- 需要生命感时，让一小片叶面舒展、一个轮轴缓慢转过，线条跟着表面走；其余部分保持安静。
- 制版场景可以让斜光缓慢经过压痕，或让刚铺下的淡彩边缘渐渐稳定；纸上的墨线不随灯光闪烁。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 从刻线局部拉远到全貌 | 细节与整体的关系 | 工艺、开场、尺度揭示 |
| 沿纸面缓慢平移 | 有顺序地观察 | 分类、地理、连续讲解 |
| 从主体推近到一个局部 | 集中注意力 | 结构、产品细节、微观 |
| 固定机位，局部排线或淡彩变化 | 让变化本身清楚 | 前后对比、状态、阅读 |

## 声音调色板

第 1 档可用短拨弦、轻敲击、低密度铺底，配少量干燥的刻划与纸张拟音；需要真实乐器质感时，再用第 2 档 Tone.js 配合授权明确的采样。声音按一组刻线或一个动作组织，避免每根细线都发声。有口播时，刮擦声尤其要轻，给辅音和句首留空间。

律动与和声（举例，不止这些）：克制的室内乐式分句、慢速分解和弦，或稀疏的现代电子脉冲。自然题材可以温和，机械题材可以精确，悬疑题材可以用持续低音；不用把仿古乐器当成必选项。

## 原生手法

- 排线逐层加深，让轮廓成为有体积的物件：适合工艺过程、知识逐步展开（经典）。
- 放大局部并移到页边，留下指回原位置的引线：适合解释结构，保留细节与整体的关系。
- 磨去局部旧线，再刻入新线：适合方案修订、结构变化和历史演变。
- 在单色图中只给正在讲的部分铺上淡彩：适合定位重点、说明状态。
- 同一组曲线从一种表面的排线延续成另一种形体：适合有关联的主题之间转场，先保证两边形体都清楚。

## 变化空间

- 结构：围绕一个物件逐层解释；沿一幅长图巡视；比较同一对象的不同版本。
- 开场：已完成的图版里先动一个细节；从极近的排线拉远；从一个需要解释的局部开始。
- 结尾：完整图版留给观众阅读；收掉辅助标注，只留主体；让最后一个细节连接到下一张图。

## 坑

- 排线方向与形体无关：先明确表面朝向与光向，让线条解释体积。
- 所有线等粗、等长、等距：加入有依据的粗细与疏密变化，但保持整片一致。
- 缩小后变灰、移动时出现摩尔纹：减少线的密度，拉开间距，必要时提高采样分辨率；以最终编码视频和手机尺寸检查为准。
- 线条穿过前景物体：遮挡关系随形体一起处理，别只叠一层通用纹理。
- 把泛黄、污渍和花边当成风格本身：先去掉装饰检查线刻是否成立，再按主题决定纸面的年代感。
- 铜色高光留在纸上：区分制版场景与印刷成品，纸上的明暗由墨线表现。
- 小字、引线与细排线挤在一起：留出注释区，分批讲解，镜头不要在注释读完前移走。
- 为了像图谱而编造学名、比例尺或结构：事实来自用户或可靠资料，虚构内容明确标为示意。
