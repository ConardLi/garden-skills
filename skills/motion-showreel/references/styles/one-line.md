# 一笔线描（one-line）

> 一条线在画面里延伸、转弯、回看，物体和关系沿着它逐渐被看见。
> 参照（只学语法）：连续轮廓绘画、极简线描动画、以路径组织叙事的动态图形。不照搬具体肖像、线稿和标志。
> 借鉴方向：[lemo-opuscar 的 One-Line Art](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/one-line/STYLE.md)，按本库结构重新整理，技术实现由 Agent 按主题探索。

## 本质 / 不是什么

- 本质：**线的连续性承担叙事**。一条路径既勾出轮廓，也连接前后事物；哪里绕行、哪里交叉、哪里留下空白，都在说明它们的关系。
- 不是：白板教学里一只手把许多独立小图依次画出，也不是 `flat-vector` 只去掉填色。路径必须有来处和去处，不能靠随意淡入淡出来掩盖断线。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 连续轮廓 | 一条线绕过多个可辨认的形体，中途不跳点 | 旅程、关联、品牌故事 |
| 回折共享边 | 线从一个形体的边缘折回，成为另一个形体 | 合作、相似与差异 |
| 负形留白 | 线只围住部分边界，空白补出主体 | 极简、情绪、想象 |
| 游走线头 | 当前生长的端点清楚，其余部分安静 | 过程、引导、寻找 |
| 线团解开 | 绕行逐渐舒展，形成可读的轮廓或路径 | 整理、理解、解决问题 |
| 局部回描 | 同一位置有少量有意重叠，表现强调 | 记忆、反复、手工感 |
| 线变文字 | 物体的边线延续成短字或字下的连线 | 命名、Logo、结论 |
| 一笔跨尺度 | 细节边缘拉远后成为更大轮廓的一段 | 微观到宏观、联系 |
| 空间折返 | 路径走出画框，稍后在另一处重新进入 | 多地点、时间跨度 |
| 单处色点 | 极少量实色留在线经过的关键位置 | 状态、情感重心、品牌 |

规则：

- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选。
- 可有辅助文字或少量独立线，但主路径始终能被追踪。交叉的多少由主题决定，不把「一笔」变成必须塞下所有细节的谜题。

## 这个风格最俗的版本

- 画面：米白底黑线从左画到右，依次勾出脸、心形和手，末尾绕成品牌名。
- 声音：独奏钢琴加铅笔沙沙声，线每拐一次弯就响一个高音。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么保留经典版。可以从已有的完整路径出发，讲一段回溯、拆解或修复。

## 适配

- 用途：品牌故事、关系讲解、Logo 演绎、概念片头、轻量循环。
- 内容：连接、旅程、创作、人与物的关系，以及能用轮廓表达的过程。
- 不适合：需要精确展示界面、密集数字或复杂机械装配的片子；一笔不能替代必要的结构信息。

## 技术路线

- **路径与显现**：SVG 和 Canvas 都适合。可从手工整理的矢量路径起步，探索按弧长控制线头位置与已显现部分；不要把曲线参数均匀推进误当成匀速书写。
- **形状转换**：Paper.js 可辅助曲线拆分、求交与整理；需要轮廓插值时可考察 Flubber，但连续线的端点、交叉和绘制方向仍须单独设计。
- **大画幅与长路径**：Canvas 或 PixiJS 可组织分段缓存与遮罩。路径延伸到画外时，保留世界坐标中的连接关系，镜头只改变观察范围。
- 任意时刻独立还原路径形态、线头与镜头；手工扰动固定种子。`--dpr` 用于圆滑边缘，`--subframes` 从轻，避免快速线头拖出多条灰线；通常不需额外 `--grain`。

以上是实现方向，具体路径规划、插值与遮挡办法由 Agent 按图形选择。

## 材质与渲染

- 工艺依据：笔尖不离开纸面，线宽和弯曲来自手腕的速度与压力。先用干净线条验证轮廓，再决定是否加入轻微压力变化。
- 主线宽度以最终尺寸可读为准，急转弯处圆滑连接，不出现尖刺或一团过黑的接头。
- 交叉点要读得懂：可以按真实描画留下重叠，也可以用很小的断口说明上下关系；同一片子保持一致。
- 负形属于构图的一部分。轮廓之间留足间距，避免一条连线误读成嘴、眼睛或零件边界。
- 如果使用纸面，纹理固定在纸上；线宽变化沿路径稳定。主体和连接线用同一套笔触，不让人物突然变成精细插画。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 纸与墨：底 `#F5F0E6` / 线 `#252A2B` / 色点 `#C35F4A`。
- 夜色细线：底 `#202C36` / 线 `#E8E5D9` / 色点 `#CBAF69`。
- 浅蓝与深绿：底 `#E9F0F2` / 线 `#244B47` / 色点 `#E08B55`。
- 推导：先保证主线与底色的明度差，再从主题里取一处强调色。色块只承担定位和强调，不能把全部轮廓填满，抢走路径的作用。

## 字体

英文可用 DM Sans、Manrope，中文用思源黑体，均自托管 OFL 版本。标题保持短，辅助文字比图形安静，但不能细到接近线稿。只有适合的短字才沿主线书写；长标题另行排版，避免为不断笔而破坏字形。

## 运动

- 线头沿路径自然推进，长直段可快，识别形体的关键转折略停。速度变化跟阅读难度走，不按每个控制点机械停顿。
- 变形时保住端点和主要交叉关系，让观众看见同一条线怎样改成新形体；跨度过大时允许借画外空间过渡。
- 进场可以从线头、负形或整条线的局部开始。退场可沿原路收回，也可让线头牵走整体，不必每次擦掉。

## 画面怎么活

- 轮廓成立后以静为主，给观众补全形体的时间，避免全线持续蠕动。
- 情感主题可让一个小线圈轻微收放，幅度只够改变松紧，不把主体拉变形。
- 旅程主题可让未完成的线头缓慢试探一个方向；已画部分不跟着无意义地抖动。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 跟随线头平移 | 正在经历的过程 | 旅程、创作、寻找 |
| 停住镜头，让路径经过 | 建立稳定的观察点 | 关系、解释、循环 |
| 拉远露出整条路径 | 局部汇成整体 | 系统、品牌、结论 |
| 回到已画过的交叉点 | 重新理解前文 | 回忆、修订、因果 |

## 声音调色板

第 1 档可用柔和拨弦、少量钢片音和轻噪声，线条形成一个可读形体时再给声音回应。需要真实弓弦、钢琴或笔尖拟音时，用第 2 档 Tone.js 配合授权采样。书写声可按长短句出现，不能持续盖住口播，也不要给每个转角打点。

律动与和声（举例，不止这些）：稀疏的自由分句、轻快的拨弦切分，或一条持续音上缓慢改变和声。路径可以从容，也可以果断，不预设成感伤钢琴片。

## 原生手法

- 线头不抬起，前一个物体延伸成下一个：适合旅程和主题关联（经典）。
- 交叉处轻轻展开，原先的线团变成清楚的关系：适合解释复杂问题。
- 镜头拉远，让多段局部轮廓成为一个更大的形象：适合共同目标和尺度转换。
- 沿主线回走，只改动一个转折，后续形体随之改变：适合选择、修复和方案对比。
- 主线绕开一块空白，最后靠负形显出标题或符号：适合含蓄揭示和记忆点。

## 变化空间

- 结构：随线前行；从完整图形倒着找原因；围绕同一交叉点展开几个关系。
- 开场：线已经画了一半；先看到被线包围的空白；一条松弛的线突然被某处牵动。
- 结尾：停在未闭合但可识别的轮廓；拉远看到整个连接；首尾接好形成自然循环。

## 坑

- 每个图形各自淡入，连接线只是装饰：先在静态路径上验证是否真能连续走通。
- 用最短连线穿过主体：绕开语义关键部位，宁可多留空白。
- 变形中交叉关系乱跳：减少同时变化的区段，先保住识别点。
- 线头速度忽快忽慢：检查实际路径长度，关键停顿另行安排。
- 过度追求一笔导致形体无法辨认：删细节，或明确采用主线加辅助线的变体。
- 字和线一样细、一样密：用字号、字重和留白区分阅读与观看。
