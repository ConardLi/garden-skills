# 数学／概念形变（concept-morph）

> 同一个对象经过可追踪的变换，让抽象关系在运动中显出来。
> 参照（只学语法）：3Blue1Brown 的数学可视化、动态几何证明、Manim 的对象对应思想。

## 本质 / 不是什么

- 本质：形变承担推理。观众既看到前后形状，也知道哪些点、长度、面积、数值或关系在变化中保留。
- 与数据动效的区别：重点是概念之间的对应，而非一组数字的展示；任意轮廓变形如果不能说明关系，只能算抽象图形。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 对应点不丢失 | 同一组点在变换前后保留颜色和身份 | 映射、坐标转换 |
| 不变量 | 一条高度、面积或距离保持明确 | 几何、守恒 |
| 公式连到图 | 符号与图中的对象共用语义色 | 数学、物理 |
| 辅助线先解释 | 投影、垂线、轨迹解释下一步形变 | 推导、测量 |
| 重排而不增减 | 小块移动但数量与面积可核对 | 组合、面积证明 |
| 单参数控制 | 角度或比例连续变化，结果跟随 | 函数、系统响应 |
| 局部高亮 | 只突出正在理解的一项 | 多变量问题 |
| 反向演示 | 变换可逆地回到起点 | 等价关系 |
| 极限过程 | 分块逐渐细化，明确有限近似 | 微积分、近似 |
| 反例扰动 | 改变一个条件，让规律失效 | 边界、假设 |

规则：按主题挑 2–3 个，至少一个不在俗套里。先说清要证明或解释什么，再选择变换。

## 这个风格最俗的版本

- 画面：黑底彩线、漂浮公式、圆变方，再加无关粒子和镜头旋转。
- 声音：空灵钢琴伴随每次显现，所有变换都响同一个 whoosh。
- brief 写清每次形变保留什么、改变什么。保留黑底彩线时，用内容准确性和可追踪的对应关系让它成立。

## 适配

- 用途：数学与科学讲解、抽象机制说明、概念关系、算法原理。
- 内容：对象之间存在明确映射，能用运动减少理解步骤的主题。
- 有单位、坐标轴、概率或近似时，必须标清口径；15 秒演示不能冒充完整证明。

## 技术路线

- 精确几何可用 Canvas、SVG 或 Manim；先建立数据层中的数学对象，再生成图形。排版较多时可考虑 KaTeX、MathJax 的自托管输出。
- D3 的比例尺、d3-shape 可辅助坐标和曲线；Three.js 适合确有三维关系的主题。
- Paper.js、Flubber 可帮助整理轮廓，但自动插值不保证语义正确。必须自己决定点对应、方向、闭合点和数量变化。
- 参数、相机与公式从同一时间轴求值，支持任意时刻重建。预先抽取特殊值和边界值，检查推导与绘图一致。
- 细线优先提高 `--dpr`；`--subframes 1–2` 足够。小点快速移动时检查运动模糊是否淹没对应关系。

## 材质与渲染

- 工艺依据：这是供人思考的图，不需要假装成物质。先建立准确几何，再用线宽、层次与颜色区分主对象、辅助线和文字。
- 主对象轮廓清晰，辅助网格更淡；低对比背景线不能与零轴竞争。
- 对应点的直径要在最终观看尺寸下可辨认，细小标记可以用短暂放大替代常驻发光。
- 形变过程采用同一采样集合。闭合曲线的接缝与重合点需要解释，不能在拆开时凭空多出一个点。
- 关键读数不要贴在移动曲线上。留出独立标注区域，用短引线明确对应。

## 配色

示例只看思路，不照抄。

- 深墨板：底 `#17252D` / 主对象 `#73D0C3` / 参数 `#F2BB68`。
- 白纸几何：底 `#F5F3ED` / 主对象 `#285D75` / 对照 `#B74A58`。
- 深紫蓝：底 `#25273D` / 主对象 `#D6DFC2` / 特殊值 `#DE997D`。

按对象身份分配颜色。量值映射用有解释的连续色阶；角色映射用离散颜色，不能在中途为了好看换色。仅靠红绿区分时补形状或文字标记。

## 字体

公式可用 STIX Two Math、Latin Modern Math，正文可用思源黑体、DM Sans，均核对授权并自托管。公式正确排上下标、括号和分数；直接 Canvas 文字适合短公式，复杂公式应预排版。主要结论比坐标小字更醒目，手机尺寸仍能读懂。

## 运动

- 解释关系时保持可追踪的平滑变换；参数读数必须跟真实参数一致。
- 几何值变化不要用可能越界的弹簧，除非过冲本来就是系统内容。
- 先建立起始状态，突出对应点，再变换，最后留读图时间。快慢由理解负担决定。
- 改变维度、拓扑或对象数量时，必须显示切分、复制、投影等步骤；不能把任意淡化称为数学推导。

## 画面怎么活

- 需要观察周期时，让一个参数缓慢运行，其他背景保持稳定。
- 到特殊值时停一下，观众能比较点、公式和读数。
- 结论以静为主。辅助线若已完成任务可退场，不能让多组扫描线继续抢注意力。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 固定坐标系 | 观察变量本身的变化 | 函数、映射 |
| 平移接续展开 | 同一对象延伸到新表示 | 展开、序列 |
| 对应处局部放大 | 看清特殊值或误差 | 极限、边界 |
| 受控三维旋转 | 显示被遮住的结构 | 立体几何 |
| 拉远到共同坐标 | 对比变换前后关系 | 归纳、总结 |

## 声音调色板

第 1 档适合低密度电钢琴、柔和木音、持续纯音和参数变化音效；需要真实钢琴可选第 2 档。音高映射数值时明确映射规则，否则只把声音用于分句和关键节点。

律动可选无拍分句、轻微的非对称节拍或缓慢单和弦。变换开始与完成各留一个声音提示即可；口播期间避免旋律与公式阅读争抢注意力。

## 原生手法

- 同一批点从一种坐标表示移动到另一种：适合映射（经典）。
- 小块不重叠地重排，显出面积或数量等价：适合几何与组合。
- 一条辅助线延长成下一幅图的坐标轴：适合把测量连接到函数。
- 固定一个不变量，只改变另一维：适合隔离影响因素。
- 演示完正例后轻改假设，让反例可见：适合说明成立条件。

## 变化空间

- 结构：从直觉图走到公式；从公式追溯几何；比较两个表示并寻找共同量。
- 开场：一个特殊值；看似不相干的两幅图；一个可直接观察的变化。
- 结尾：把对应关系停在同一屏；反向回到起点；留出一个可验证的新参数。

## 坑

- 轮廓很顺但点配错了：先检查起点、方向、点数及对应规则，再做插值。
- 旋转或缩放偷偷改变了比较口径：统一坐标与单位，或明确显示换算。
- 采样线段与数学连续曲线混用：写明离散近似及误差，不伪造极限已完成。
- 公式切换后颜色改义：对象、符号和图例共用同一份语义映射。
- 开场还没认清就开始变：为起止状态留停顿，减少同时移动的对象。
- 只验证三个静帧：中途可能交叉、倒置、跑出边界，必须看连续帧并核对特殊值。
- 闭合曲线的参数首尾重合，展开时却被当成一个点：明确参数接缝，重合时合并显示标注，拆开后分别跟随各自端点。
- 中途对应点靠得很近，标注仍全部贴着走：保留点的颜色，在拥挤阶段暂时收起文字，终态再落到稳定坐标轴上。
