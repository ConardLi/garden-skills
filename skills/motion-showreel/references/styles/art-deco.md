# 装饰艺术（art-deco）

> 阶梯、扇面和成组的平行线围绕一根秩序清楚的轴线展开，装饰本身负责组织画面。
> 参照（只学语法）：装饰艺术建筑立面、交通海报、金属镶嵌与漆面工艺。不照搬具体建筑轮廓、海报构图、商标和字体文件。
> 借鉴方向：[lemo-opuscar 的 Art Deco](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/art-deco/STYLE.md)，按本库结构重新整理，技术实现由 Agent 按主题探索。

## 本质 / 不是什么

- 本质：**把机械时代的秩序变成装饰**。重复线条有间隔，阶梯有层级，轴线控制重心；图案、字和主体像同一套建筑构件，开合、升降都服从这套结构。
- 不是：给 `dark-keynote` 加一圈金边，也不是任意黑金奢华海报。放射线和对称不必每次出现，但几何装饰必须参与构图，不能只是贴花。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 阶梯轮廓 | 宽度逐级收窄的台阶、塔冠或字框 | 上升、里程碑、等级 |
| 扇形展开 | 一组扇骨从共同轴心依次张开 | 揭幕、选择、汇聚 |
| 成束平行线 | 等距线在转角处一起折返，形成轨道 | 交通、连接、流程 |
| 几何镶嵌 | 金属细条分隔漆面、石材或纯色色面 | 工艺、品牌、精密 |
| 纵向拉伸 | 高挑门洞、窄长字面、向上的分层 | 建筑、雄心、纪念 |
| 偏轴海报构图 | 主体沿斜线推进，留出清楚的标题区 | 旅行、速度、现代生活 |
| 嵌套拱门 | 门框套着门框，尺度向内递减 | 进入、层次、探索 |
| 角部折线 | 直角、倒角和短折线约束边界 | 名牌、证书、信息分区 |
| 几何植物 | 叶片、羽毛被整理成重复的扇面与弧段 | 自然、生活方式、季节 |
| 拉丝定向反光 | 金属条只沿同一工艺方向出现窄反光 | 质感、产品、细节 |

规则：

- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选。
- 先定主轴、比例和留白，再放装饰。同一层级的线宽与间距保持一致，不要求全片左右镜像。

## 这个风格最俗的版本

- 画面：黑底金线、正中日芒、两边对称扇面，门打开后出现宽字距标题，最后撒金粉。
- 声音：大乐队铜管齐奏，开门必配镲片，落版必来一次盛大的和弦。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么保留经典版。可以从交通海报的斜向速度、浅色漆面或局部镶嵌入手。

## 适配

- 用途：品牌宣传、活动片头、Logo 演绎、作品集章节、里程碑展示。
- 内容：建筑、交通、工艺、文化活动，以及希望表现秩序和仪式感的现代品牌。
- 不适合：密集操作教学、需要大量长句的说明，或靠随意手绘和自然松弛成立的主题。

## 技术路线

- **图形与排版**：SVG 或 Canvas 适合阶梯、扇面、平行线与遮罩。可考虑 Paper.js 整理重复路径和曲线交接，先验证几何节奏，再加表面质感。
- **金属与漆面**：以平面海报为主时，可探索 Canvas 渐变或 PixiJS 的局部材质遮罩。需要门框厚度、镶条侧面和移动高光时，再考虑 Three.js。
- **运动组织**：按构件分组处理轴心、轨道与开合方向；库可以辅助几何和插值，不把库的实时播放状态作为帧依据。
- 同一时刻独立还原所有构件的位置与光照，拉丝纹理固定种子。细金属线先在最终尺寸下检查；`--dpr` 视边缘质量增加，`--subframes` 从低值试起，`--grain` 只在确有印刷或漆面需要时加入。

以上是候选方向，不规定几何生成算法、材质实现或库的组合。

## 材质与渲染

- 工艺依据：金属镶条、漆面和石材各有边界。先建立分区，再决定哪一块有反光；整屏统一金属渐变会把镶嵌变成塑料贴纸。
- 金属条宽窄有层级，转角连接干净；交叉位置明确谁连续、谁截止，避免线头互相穿出。
- 漆面保留大块平整暗面，反光少而宽；拉丝金属的纹理方向随构件走。印刷版本则用平面墨色，不必模拟真实金属。
- 高光由光源与表面方向决定。同一扇门上的镶条共同响应，不能每一根线各自扫光。
- 主体或 Logo 也按几何结构整理轮廓；有官方品牌资产时保留其形状，把装饰放在承托结构上。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 深漆与黄铜：底 `#162C2A` / 金属 `#C4A064` / 字 `#F3E9D5`。
- 象牙与朱砂：底 `#EEE3CC` / 主色 `#963F32` / 深线 `#263C42`。
- 午夜与银色：底 `#18243B` / 主色 `#BFC6D0` / 强调 `#93714F`。
- 推导：从品牌取一个主色，配大面积稳定底色，再给线与字足够反差。金银只占结构中的少量位置；浅底、哑光或无金属版本同样成立。

## 字体

英文展示可选 Poiret One、Josefin Sans，辅助用 Jost；中文用思源黑体或思源宋体，自托管 OFL 字体。展示字可稍放宽字距，正文保持正常阅读密度。细字体放大用，标签用较实的字重；几何字框不能压住文字的呼吸空间。

## 运动

- 阶梯沿同一方向逐级抬升，扇面围绕明确的轴心张开，轨道里的线匀速通过转角。构件有机械行程，停下时干净。
- 主动作用平稳加速和短减速，允许一组构件有小幅错时。避免所有装饰各自弹跳，把有秩序的组合拆散。
- 进场可由遮挡、升降或套叠完成；离场顺着已建立的轨道收回，也可保持框架只更换内容。

## 画面怎么活

- 落版以静为主，标题和框架稳定，允许一束窄反光缓慢经过一条金属边。
- 有机械主题时，一小组扇骨或刻度做低幅往复，运动范围不跨进阅读区。
- 印刷海报版本可以完全静止，靠局部切换重心延续节奏；纸纹和墨色不用持续抖动。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 正面固定，构件开合 | 仪式与秩序 | 片头、Logo、信息揭示 |
| 沿纵轴缓慢上移 | 层级与上升 | 里程碑、建筑、成长 |
| 顺斜向主线平移 | 速度与目的地 | 交通、旅行、连接 |
| 从镶嵌局部拉远 | 工艺组成整体 | 品牌、产品细节 |

## 声音调色板

第 1 档可用短拨弦、圆润贝斯、轻手鼓和少量金属敲击，表达构件的开合与落位。需要铜管、簧管或刷鼓质感时，用第 2 档 Tone.js 配合授权采样；不要用刺耳的合成短音冒充真实铜管。反光不必配音，声音优先跟结构变化。有口播时减少中频齐奏。

律动与和声（举例，不止这些）：轻快的切分与摇摆、庄重的慢速和弦，或平直克制的现代电子节奏。年代感由画面和配器共同决定，不强制每支都做爵士派对。

## 原生手法

- 扇面或套门围绕主轴展开，露出内容：适合揭幕、片头（经典）。
- 平行镶条从边框转成道路或连接线：适合交通、组织关系和服务网络。
- 阶梯轮廓逐层改变宽度，构成下一组图形：适合等级、成长和阶段推进。
- 斜向海报里的速度线收拢成题签边界：适合从过程切到结论。
- 同一构图在平面印刷与浅浮雕之间切换：适合工艺、材质版本或品牌细节。

## 变化空间

- 结构：围绕一根轴线逐层揭示；沿斜向路线穿过几个主题；同一框架比较不同版本。
- 开场：先见偏角的一段镶条；大色面中出现一个阶梯缺口；主体已经在场，装饰随后响应。
- 结尾：保留完整的几何名牌；装饰退到角部让内容居前；沿最后一条轨道自然接回开场。

## 坑

- 去掉金色就认不出风格：先用单色检查阶梯、线束和比例是否成立。
- 装饰比主体复杂：降低装饰层级，让观众先看内容，再看工艺。
- 所有镜头强制居中对称：允许斜向和偏轴构图，靠重复比例维持一致。
- 线宽随缩放忽粗忽细：明确哪些属于真实构件、哪些属于平面版式，分别处理。
- 大片发光和金粉遮住几何关系：控制高光范围，保住暗面与硬边。
- 标题字距过大、中文被横向压缩：用合适字体与留白调整，不拉坏字形。
