# 泥金手抄本（illuminated-manuscript）

> 墨字、矿物色、泥金或金箔留在羊皮纸上，首字母和页边装饰带着故事缓缓活起来。
> 参照（只学语法）：欧洲彩饰手抄本、哥特式装饰首字母、页边细密画。

## 本质 / 不是什么

- 本质：以书页为构图单位，把文字、插图和贵重金饰组织成同一件手工作品。金色的材料变化与纸页的安静共同构成质感。
- 泥金绘饰与贴金箔的表面不同，按选定工艺处理；不要把所有金色都画成镜面。彩色玻璃依赖透光，这里依赖纸上颜料与金属的反射。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 装饰首字母 | 大字母与植物或细密画嵌套 | 文学、开篇、品牌首字母 |
| 有起伏的金地 | 金饰有细纹、接缝或压印 | 工艺、珍藏 |
| 局部反射 | 光走过时，只有金属区域明显变亮 | 发现、唤醒 |
| 羊皮纸页面 | 温润纤维、边缘色差、浅褶皱 | 书籍、记忆 |
| 红蓝矿物色 | 平涂颜料厚实，墨线精细 | 历史、寓言 |
| 页边藤蔓 | 茎叶围绕版心，不覆盖正文 | 生长、时间 |
| 朱红引题 | 短题或首句用红色标明层级 | 章节、命名 |
| 页边小生灵 | 鸟兽在书页边界里作有限表演 | 轻寓言、文化 |
| 双栏或整齐书写行 | 文字行距稳定，插图打破局部秩序 | 阅读、档案 |
| 手工压印 | 金地上的点纹和刻线随光显隐 | 细节、材质 |

规则：每支挑 2–3 个，至少一个不在俗套里。具体地域、年代和书体要有依据；幻想创作明确标为当代演绎。

## 这个风格最俗的版本

- 画面：黄纸、黑体哥特字、满屏金色渐变、对称藤蔓、漂浮星光。
- 声音：庄严合唱加钟声，每次金色发亮都响魔法铃。
- brief 写明保留哪些古典信号、如何从主题重新安排书页。可以小而幽默，也可以严肃，不预设宗教故事。

## 适配

- 用途：文化艺术片头、书籍宣传、文学主题、珍藏工艺、短寓言。
- 内容：值得慢读的文字、书页里发生的动作、装饰与意义相互关联的题材。
- 精确复原须注明时代和来源；没有史料依据的细节作为幻想设计，不宣称文物复刻。

## 技术路线

- Canvas 或 SVG 分开纸面、颜料、墨线、金饰和动态插图。静态复杂装饰可以缓存，只有光与动作按时间更新。
- 金饰单独建立几何遮罩与材质层，不用按画面黄色阈值误选纸面和皮肤。WebGL 可处理细法线、粗糙度和方向光反射；Canvas 可用固定纹理加受控光带近似。
- 有翻页或明显侧视时考虑 Three.js 的薄页网格、双面材质与局部弯曲。正面书页不必为技术复杂度强加三维。
- SVG 路径适合藤蔓展开和有限关节动画；Paper.js 可辅助曲线整理。插画仍须人工检查结构和遮挡。
- `--subframes 1–2` 适合慢动作；细装饰可提高 `--dpr`。纹理在纸面坐标中固定，不靠逐帧全屏噪点。

## 材质与渲染

- 工艺依据：书页先留出版心与插图位置，再画墨线、填颜料，局部施金并磨光或压饰。让各材料占据不同的反射范围。
- 羊皮纸以低对比纤维、局部色差和边缘暗化组成。污点不能盖过字，纹理缩小后应仍是一张纸。
- 矿物色以饱满平涂为主，轻微不匀来自颜料厚薄；主体、叶片和首字母一起处理，避免光滑角色贴在旧纸上。
- 贴金可有细碎褶纹、微小接片和明暗突变；泥金笔绘则更细哑、更均匀。压印暗缘与亮缘要服从同一入射方向。
- 金属高光由光源或观察方向变化产生，限制在金饰遮罩内。宽光带负责材料感，少量细亮点只作点缀，不能全靠星星代替金属。

## 配色

示例只看思路，不照抄。

- 朱蓝金：纸 `#EDE0BF` / 蓝 `#294A79` / 朱 `#A93F35` / 金 `#B58A39`。
- 植物手稿：纸 `#EAE3CA` / 绿 `#415F46` / 墨 `#45372D` / 金 `#C3A458`。
- 暮色书页：纸 `#DCCCAE` / 紫 `#63516D` / 红 `#9A414C` / 金 `#AA7D34`。

先确定纸、墨、主颜料和金属，金属亮处可以接近淡奶白，暗处仍要保留棕黄；避免把它做成普通黄填色。正文以深墨保证对比。

## 字体

拉丁短题可用自托管 OFL 的 UnifrakturMaguntia、Cormorant Garamond；中文可用思源宋体。黑体哥特书体只用于能读清的短内容，不能让长段正文靠装饰字体硬撑。历史原文须查证；当代创作可用明确可读的中文，不编伪拉丁语。

## 运动

- 以书页为稳定舞台，藤蔓、鸟兽、字母按内容作局部动作；动作幅度受插画比例和页边空间约束。
- 叶子依茎的顺序展开，动作可以稍有延迟，但不能所有装饰一起呼吸。
- 光的移动连续、方向一致；镜头停下后保留一次缓慢反射，再给安静落版。
- 翻页时处理正反面、阴影和遮挡。没有翻页需求就保持纸页稳定，不用万能书本转场。

## 画面怎么活

- 一片叶子在动作发生处微微弯动，远处叶片安静。
- 金地随一束移动的光改变明暗，纸与颜料保持哑光。
- 页边生灵短暂回头、探身或沿墨线走动，完成后回到可阅读的姿态。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 金饰微距拉远 | 从工艺细节看见书页 | 珍藏、开篇 |
| 沿版心缓慢移动 | 跟随文字或边饰 | 阅读、旅程 |
| 固定整页局部表演 | 装饰内发生故事 | 寓言、角色 |
| 轻微斜视或掠光 | 让压印和金属可见 | 材质、工艺 |
| 有依据的翻页 | 时间或章节推进 | 文学、历史 |

## 声音调色板

第 1 档可用稀疏拨弦、柔和风琴、低强度摩擦与翻纸合成；想要具体古乐器时用第 2 档加可授权采样，并如实标注音源。不要把合成拨弦称为真实鲁特琴录音。

律动可选自由拍的开放五度、轻缓三拍、细密的拨弦问答。小幅光泽变化不必触发声音；大空间混响要给纸页拟音留下近距离感。

## 原生手法

- 首字母里的枝叶延伸到页边：适合故事从文字里展开（经典）。
- 一次掠光显出原先不明显的压印：适合发现与珍藏。
- 页边生灵走入插图，再返回文字旁边：适合书内世界与阅读的关系。
- 墨线先留下形状，颜料和金饰分层显出：适合工艺过程。
- 纸页轻弯，金饰亮起而颜料保持不变：适合材料对比。

## 变化空间

- 结构：从金饰细节看见全页；全页里的局部小故事；按书写与施金过程逐层完成。
- 开场：一块尚未辨认的压印；已经打开的书页；版心旁一处异常活动。
- 结尾：回到能静读的整页；一个动作藏进页边；留下明确的下一页入口。

## 坑

- 黄褐纸和金色一起扫亮：用专用金饰遮罩，分别检查纸、颜料和金属区域的亮度变化。
- 只有渐变没有微结构：补固定褶纹、接片或压饰；泥金与贴金不要混成同一种表面。
- 星光太多、整页在发光：减少闪点，用反射方向和粗糙度说明材料。
- 文字被藤蔓围得太紧：先留版心，再铺装饰。镜头拉远后复查中文和短题。
- 背景旧、主体像矢量贴纸：共享墨线与颜料纹理，保持边缘处理一致。
- 全页装饰持续摇晃：只动故事发生处，其他区域为阅读留静。
- 近景拉远时正文在画框边缘露半截：正文在可完整阅读的取景下再出现，或提前调整版心与镜头。
- 角色起点和终点避开了文字，中途却飞过标题：给整段轨迹留禁入区，检查翅膀、尾羽等超出重心的部位。
