# 合成波霓虹（synthwave-neon）

> 80 年代复古未来：地平线上的日落、向远处延伸的霓虹网格、镀铬大字、发光的线。
> 参照（只学语法）：synthwave / outrun 视觉、80 年代电影海报和片头的镀铬字。不照搬具体作品、电影标识和专辑封面。

## 本质 / 不是什么
- 本质：**透视网格地面 + 分层的落日 + 霓虹描边 + 镀铬或渐变大字**；发光有来源（霓虹管、太阳），暗部是深紫和深蓝。
- 不是：AI 默认的紫粉渐变加到处发光。这是一种明确的复古类型，元素和构图都有讲究；用户没有指名或者主题不匹配时，不要用。

## 适配
- 用途：片头、音乐向短片、复古主题的宣传、作品集的一段。
- 内容：音乐、游戏、复古品牌、夜生活、汽车。

## 技术路线
Canvas 2D（透视网格用投影公式画线）+ WebGL 后期做 bloom 和轻微的扫描线；或者 Three.js 搭网格地面和远山（正交或透视相机），后期加 bloom。霓虹线 = 一条亮色细线 + 多层越来越宽、越来越淡的同色线（或 bloom）。

## 材质与渲染
- 地面：透视网格，横线间距随距离指数缩小，随时间向镜头滚动（`offset = (t * speed) % gap`）。
- 太阳：半圆 + 竖向渐变 + 水平的切口条纹（条纹间距从上到下变大）。
- 远山：低多边形剪影，叠一层雾。
- 镀铬字：竖向多段渐变（天蓝 → 白 → 深蓝 → 橙）+ 亮边 + 一个星芒高光。
- 星空：固定种子的点，偶尔闪烁。

## 配色
- 深紫 `#140A2E` / 洋红 `#FF2E97` / 青 `#00E5FF` / 橙黄 `#FFB300`
- 深蓝 `#0B1033` / 粉 `#FF6AD5` / 紫 `#8C52FF` / 落日橙 `#FF7E5F`
- 规则：霓虹色最多两种；发光只给霓虹线、太阳和字，背景保持暗。

## 字体
80 年代感的展示字体：Monoton、Audiowide、Michroma、Orbitron（谨慎）、粗斜体（Russo One）；手写霓虹字可以用 Pacifico / Mr Dafoe 类（OFL）。

## 运动
- 网格地面匀速滚动（表达前进，匀速是对的）；大字用弹簧 `{1.6, 0.9}` 推出或者从地平线升起。
- 霓虹亮起：先闪两下（亮暗 1–2 帧），再稳定亮着。
- 节拍：每个重拍让霓虹亮度脉冲一次。

## 镜头语法
| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 贴地向前飞行 | 速度、前进 | 开场、过渡 |
| 抬头仰拍大字 | 宏大 | 标题、logo |
| 横移沿地平线 | 巡游 | 段落 |

## 声音调色板
合成波：门控的大混响军鼓（`snare` + reverb 0.5）、八分音符的锯齿贝斯（`bass` 带 glide）、宽锯齿铺底（`pad` voices 7、cents 20）、主旋律 `lead`（saw，带颤音）。BPM 90–118。第 1 档合成很合适。

## 原生手法
- 字从地平线升起并亮起霓虹：适合片头和 logo。
- 太阳条纹随节拍开合：适合卡点。
- 穿过一个霓虹框进入下一镜：适合转场。

## 变化空间
- 结构：一次午夜驾驶；一块霓虹招牌逐个点亮；日落到星空的一次变化。
- 开场：漆黑中网格从远处亮起；一个霓虹管闪两下亮起。
- 结尾：太阳沉下地平线，只剩 logo 在发光。

## 坑
- 一不小心就成了 AI 默认的紫粉渐变：严格按网格 + 太阳 + 霓虹线的结构来做，别泛用。
- 发光太多，画面糊成一团：bloom 只给亮部（阈值 > 0.8）。
- 渐变在编码后出现色带：加轻微颗粒（`--grain 3`）。
