# 80 年代赛璐璐动画（cel-anime-80s）

> 手绘背景托住硬边色块的角色，少量关键姿态、局部动作和摄影台镜头共同完成表演。
> 参照（只学语法）：20 世纪 80 年代赛璐璐动画的上色与合成、有限动画、手绘背景和多层摄影。不照搬具体角色、机体、标志性镜头或配乐。

## 本质 / 不是什么

- 本质：**角色色层、背景画和摄影运动各司其职**。角色用清楚轮廓与少数硬边阴影表达体积，背景容纳更细的色彩变化，表演依靠有分量的关键姿态。
- 不是：`comic-pop` 的分格和拟声字，也不是给现代平滑动画套颗粒与 VHS。旧式合成质感可以轻微存在，决定风格的仍是绘画层次和动作取舍。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 硬边阴影 | 角色以少数明确的亮暗色面塑形 | 人物、机械、力量 |
| 手绘背景 | 环境有笔触和色彩层次，细节比角色丰富 | 世界、情绪、地点 |
| 保持关键姿态 | 一个姿态停住，眼神或衣摆局部变化 | 情绪、决心、对白 |
| 多层摄影 | 前景、中景、背景以不同速度移动 | 旅程、空间、揭示 |
| 极短冲击画 | 动作峰值出现高反差的简化姿态 | 碰撞、转折、爆点 |
| 涂抹与拖影画 | 快动作中用变形轮廓连接关键姿态 | 速度、跳跃、转身 |
| 摄影台推拉 | 对较大的绘制画面推近或平移 | 环境、观察、情绪 |
| 机械高光切换 | 硬质面随转动换到新的亮暗色块 | 设备、载具、精密 |
| 光学辉光 | 少数亮源有柔边扩散，暗部仍清楚 | 夜景、能量、氛围 |
| 有限特效帧 | 烟、火或水由少量明确形状轮换 | 环境、动作、余波 |

规则：

- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选。
- 年代感不等于每个镜头都要机甲、速度线和胶片脏点。选定角色线条、色层和动作密度，跨镜头保持一致。

## 这个风格最俗的版本

- 画面：红色天空、巨大机体、风吹长发，镜头推近眼睛，白闪后出现片名。
- 声音：电吉他主旋律配密集鼓点，任何转身都有夸张破风声。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么保留经典版。日常空间、静物、交通和轻喜剧也能用赛璐璐语言。

## 适配

- 用途：动画式产品概念片、游戏预告、故事片头、角色宣传、音乐向作品。
- 内容：明确动作、情绪转折、空间氛围，也适合把器物和机器当成主角。
- 不适合：写实人物表演、复杂手部近景或低成本长时间连续全身动作。代码能力不足时简化角色和动作，保住关键姿态。

## 技术路线

- **分层合成**：Canvas 或 PixiJS 可组织背景画、角色色层、特效与前景；角色可用自主绘制矢量或授权图集，背景与角色采用不同细节密度。
- **动作**：探索关键姿态切换、局部关节运动与手工过渡帧；SVG 可处理简单形变。不要默认给所有姿态做平滑补间，绘制帧的停留本身就是节奏。
- **机械与复杂空间**：Three.js 的卡通材质和轮廓可作为辅助方向，但需要校准阴影分区、线宽与透视，不能直接把默认三维渲染当手绘成片。
- 指定时刻独立选取姿态与特效帧，背景位移连续可还原，纹理固定种子。`--subframes` 对保持帧从轻或关闭，避免合出多张重影；`--dpr` 保轮廓，`--grain` 只加少量摄影质感。

以上是实现方向，不规定角色引擎、绘制帧率或逐镜头动作。

## 材质与渲染

- 工艺依据：轮廓和颜色画在透明片上，叠放到背景前拍摄。角色表面颜色平整，背景可以保留颜料与纸面的变化，二者不必使用同一滤镜。
- 线条顺着形体走，转折、前后遮挡和五官有明确取舍；外轮廓可稍重，内部线不能全部像黑色铁丝。
- 阴影是设计过的色块，跟着角色体积和光向变化。单纯把照片分成三档明暗，很难得到清楚的脸和手。
- 背景的笔触固定在环境上；透明片可有极轻的层间差异，但不要每帧随机漂移，损坏画面稳定性。
- 光学辉光只围绕亮源；阴影和描边保留色彩。主体、载具与角色都经过同样的色层处理，避免精细三维物体突然混进画面。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 午后街道：背景 `#B9C8C7` / 角色 `#C97954` / 阴影 `#665C76` / 亮色 `#EBD8A8`。
- 夜间设备：背景 `#263A56` / 主体 `#899AA7` / 阴影 `#34455F` / 亮源 `#DF9B69`。
- 夏日室内：背景 `#E0D6B4` / 主体 `#6D9990` / 阴影 `#527274` / 强调 `#B6564D`。
- 推导：先按场景光色确定背景，再给主体分配能分离出来的色组。阴影可以偏冷或偏暖，不能只把主色一律压黑；亮源与强调色控制数量。

## 字体

英文展示可选 Barlow Condensed、Archivo Black，辅助用 IBM Plex Sans；中文用思源黑体或思源宋体，自托管 OFL 字体。片名字体按情绪选，不强制倾斜粗字。长字幕保持稳定，放在有足够反差的区域，不套复杂描边和发光。

## 运动

- 先设计准备、发力和停住的姿态，再决定中间需要多少绘制帧。快动作可以少帧，表情转折则留够停顿。
- 角色保持时，镜头、背景或一个局部仍可动；不同层不必共用同一种步进节奏。
- 冲击画和拖影画只用于动作峰值，避免连续高反差闪烁。退场可以由角色越过镜头、环境遮挡或色面切换完成。

## 画面怎么活

- 保持姿态中偶尔眨眼、轻微呼吸或衣角摆动，身体主轮廓不持续变形。
- 背景里的窗帘、蒸汽或灯光用少量状态变化，周期不要与人物完全一致。
- 行驶场景让背景平移、车身小幅震动，人物可以大部分静止；保持视线与支撑关系。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 在保持姿态上缓慢推近 | 情绪逐渐明确 | 人物、决心、发现 |
| 多层横移 | 环境与行进 | 旅行、城市、载具 |
| 固定机位等待动作进入 | 动作的方向与重量 | 出场、碰撞、喜剧 |
| 从环境细节拉到全景 | 地点与气氛 | 世界介绍、过渡 |

## 声音调色板

第 1 档可用 FM 贝斯、合成弦乐感铺底、鼓与短噪声动作音；需电吉他、真实鼓组或管弦乐时，用第 2 档 Tone.js 配合授权采样。动作音强调准备与落点，不给每张中间帧配声。口播或对白存在时，主旋律与破风声让位。

律动与和声（举例，不止这些）：有推动力的流行节奏、温暖的日常和声，或稀疏低音支撑的悬疑氛围。年代感可以从音色来，不必借用熟悉作品的旋律。

## 原生手法

- 保持一张有力姿态，只让局部与镜头继续动：适合情绪和角色建立（经典）。
- 快动作压成一张拖影画，再落到清楚的结果姿态：适合速度和力量。
- 前景摄影层掠过，切到下一张背景画：适合行进和空间转换。
- 灯光切换带动角色硬边阴影整体换形：适合状态变化与戏剧转折。
- 特效形状在散去时留下下一镜的主轮廓：适合能量、余波和片头衔接。

## 变化空间

- 结构：围绕一次动作建立起因与结果；在环境中等待一个变化；以几个保持姿态串起旅程。
- 开场：角色已在动作准备中；先看环境里不寻常的细节；从一个静物的受光变化开始。
- 结尾：停在有余韵的姿态；动作完成后回到安静背景；角色离开，留下发生过变化的空间。

## 坑

- 颗粒很旧，动作却像平滑网页补间：重新安排关键姿态和停留。
- 角色与背景细节一样密：降低角色色层复杂度，让背景承担环境信息。
- 只做整张角色贴图平移：至少设计重心、朝向与接触点变化。
- 阴影每帧跳到无关位置：依据体积和光向设计色块。
- 保持帧经运动模糊后变成双影：减少子帧，明确哪些层需要步进。
- 冲击画频繁闪白：减少次数与亮度变化，让动作本身承担冲击。
- 默认调用熟悉角色和场景：重画主体与环境，只借媒介语法。
