# 橡皮管动画（rubber-hose）

> 四肢像柔软的管子一样弯曲，角色先蓄力再弹出去，连身边的器物也会跟着节奏做出反应。
> 参照（只学语法）：早期橡皮管动画、无明显肘膝的曲线角色、音乐驱动的拟人表演。不照搬经典卡通角色、轮廓组合、标志性道具或旋律。

## 本质 / 不是什么

- 本质：**用连续曲线和夸张的蓄力、挤压、伸展完成表演**。角色可以暂时违背解剖，但重心、接触点与动作因果仍然清楚；肢体弯得越自由，落点越要准确。
- 不是：`comic-pop` 的静态分格冲击，也不是 `soft-3d-toy` 的柔软三维材质。这里的弹性来自二维轮廓与姿态设计，旧胶片噪点只是可选表面。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 无肘膝曲肢 | 手臂与腿像弯管，转弯连续顺滑 | 角色、轻喜剧、动作 |
| 挤压与伸展 | 身体压低再拉长，重量感仍在 | 蓄力、跳跃、反应 |
| 提前反向动作 | 往右走前先往左压，观众预感下一步 | 期待、惊喜、因果 |
| 圆弧运动 | 手脚沿大而清楚的弧线移动 | 舞蹈、工作、表演 |
| 器物拟人 | 水壶、工具或字母临时长出表情和动作 | 品牌、功能、故事 |
| 节奏性步态 | 走路的落脚、摆臂和身体起伏互相配合 | 旅程、循环、行进 |
| 延迟跟随 | 手套、耳朵或配件在主体停住后再落位 | 重量、余韵、幽默 |
| 简洁面部形变 | 眼口的大小和位置表达明确情绪 | 反应、情感、短叙事 |
| 弯管传力 | 一个动作沿身体或连接物传到另一端 | 协作、连锁、功能 |
| 舞台式留白 | 单纯背景衬托清楚的动作剪影 | 角色介绍、Logo、表演 |

规则：

- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选。
- 白手套、缺角眼和黑白画面都不是必选项。先把角色轮廓与动作做成自己的，再考虑时代装饰。

## 这个风格最俗的版本

- 画面：黑白圆头角色戴白手套，在胶片划痕里左右摇摆，最后跳进圆形收幕。
- 声音：旧爵士乐从头到底，脚步、眨眼、挥手都紧贴一个乐器音符。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么保留经典版。可以用现代配色、器物主角或克制的单次反应。

## 适配

- 用途：吉祥物与品牌宣传、轻喜剧功能讲解、Logo 演绎、音乐卡点、循环。
- 内容：有明确欲望或任务的角色、能看见原因和结果的小动作、器物之间的合作。
- 不适合：严肃事故复盘、真实人体运动教学，或全靠复杂对白和微妙面部表演推进的内容。

## 技术路线

- **轮廓与肢体**：SVG 或 Canvas 适合连续曲线、封闭形状与粗细统一的描边。Paper.js 可辅助曲线变形和形状处理，肢体的弯曲方向仍按姿态设计。
- **角色组织**：可以探索简单骨架、控制曲线或关键轮廓插值；PixiJS 适合多层角色与纹理。不要让默认骨骼硬折角破坏橡皮管轮廓。
- **表演与同步**：动作关键点从本片时间表取值，声音也读同一组动作落点；曲线插值库只是辅助，不采用无法乱序还原的实时弹簧状态。
- 任意时刻能独立还原挤压、伸展、接触与配件滞后。旧片纹理若使用则固定种子；`--subframes` 从轻，先检查快速姿态是否糊掉；`--dpr` 保描边，`--grain` 可关闭。

以上是候选方向，不规定角色骨架、弹性公式和动画引擎。

## 材质与渲染

- 制作依据：二维墨线包住平整色块，形体能伸缩，但轮廓始终简明。先看黑色剪影能否说明动作，再加五官与装饰。
- 挤压时身体变宽，伸展时适当变窄，保留近似体量；不能只拉长一根轴，让角色像被缩放工具扯坏。
- 手脚接触地面或物件时短暂锁住，身体继续蓄力；离开接触点后再恢复自由曲线。
- 四肢交叉时明确遮挡，手套、鞋或其他端部形状帮助认清方向；这些端部可以原创，不必复刻经典组合。
- 背景也可拟人，但线条、填色和阴影层级与角色相容。胶片颗粒若存在，强度不能遮住表情，划痕不能每帧换位置抢戏。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 墨色与暖纸：底 `#EDE3CF` / 主体 `#292725` / 强调 `#BE684E`。
- 奶油与深绿：底 `#F0DFC0` / 主体 `#42685B` / 配件 `#CE8B45` / 线 `#2B3530`。
- 淡蓝与砖红：底 `#CEDFE1` / 主体 `#AA554B` / 辅助 `#E9C87D` / 线 `#303039`。
- 推导：角色用少数大色块，深色轮廓与背景分离；品牌色可以落在身体或道具上。黑白成立，有限彩色也成立，不能靠棕黄滤镜决定年代感。

## 字体

英文展示可选 Archivo Black、Bowlby One SC，辅助用 DM Sans；中文用思源黑体，自托管 OFL 字体。展示字可随情绪轻微弯曲，但长句保持正常字形。文字拟人时先保证读得出，再做四肢与表情。

## 运动

- 动作通常先有准备，再快速发力，最后带少量过冲和跟随；停顿是喜剧节奏的一部分。
- 身体走圆弧，四肢呈连续弯曲；允许极端伸展作为瞬间强调，但必须落回可辨认的姿态。
- 一组动作围绕一个明确目的展开。进场可探头、被拉入或大步跨入；离场也需要原因，不能所有对象无缘无故弹走。

## 画面怎么活

- 角色等待时轻轻换重心、脚尖敲一下或看向目标，动作之间有安静间隔。
- 配件在主体停下后做一次小幅余摆，逐渐停稳，不永远振荡。
- 拟人器物可偶尔回应主角，例如盖子抬一下；背景不与主角一起全屏律动。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 固定舞台式全身景 | 看清准备、动作与结果 | 喜剧、功能、循环 |
| 随角色横移 | 持续的任务或行进 | 旅程、品牌故事 |
| 动作停下后小幅推近 | 强调反应 | 表情、惊喜、结论 |
| 拉远露出牵动角色的另一端 | 补出动作原因 | 连锁、协作、反转 |

## 声音调色板

第 1 档可用拨弦、木质打击、圆润贝斯、短滑音和噪声动作音。需要真实簧管、铜管、班卓或刷鼓时，用第 2 档 Tone.js 配合授权采样。音乐可回应关键动作，但只挑准备、触地和意外等少数点，留出无声反应；有口播时避免密集滑音抢字头。

律动与和声（举例，不止这些）：轻快摇摆、带空拍的切分，或现代简洁的弹性节奏。慢动作喜剧也可用稀疏低音，不把拟人动画统一写成忙碌爵士。

## 原生手法

- 先压低身体，再拉成长弧跳向目标：适合蓄力与行动（经典）。
- 手臂伸长牵动远处物体，拉远才看见另一端：适合连接、服务和喜剧揭示。
- 一个碰撞沿身体传到配件，再引起下一件器物反应：适合连锁与协作。
- 字母暂时弯曲参与动作，落位后恢复可读标题：适合 Logo 和短标题。
- 角色身体短暂成为门、桥或工具，完成任务再恢复：适合功能隐喻，先确保用途容易理解。

## 变化空间

- 结构：围绕一个小任务反复尝试；动作在几个器物间传递；一个角色与同一物件产生不同反应。
- 开场：角色已被某物牵住；先见一个夸张准备姿态；普通器物突然做出很小的回应。
- 结尾：任务完成后停一下再给反应；道具恢复原状、角色离开；动作自然返回最初的准备姿态。

## 坑

- 只有弹簧缩放，没有表演：补上目的、准备、接触和结果。
- 管状四肢出现硬折角：调整曲线连续性，让肢体从肩胯自然接出。
- 脚底一直滑：落脚阶段锁住接触，身体重心从上方经过。
- 所有东西不停上下弹：一次突出一个动作，其余对象保持参照。
- 极端伸展后体积暴涨：同时调整宽度与轮廓，检查剪影。
- 音乐逐帧打点让人疲劳：只保留有因果作用的声画同步。
- 用熟悉的眼睛、手套、头形拼出近似经典角色：重做轮廓与配件组合，建立原创主体。
- 蓄力切到腾空时突然变形：衔接处同时检查身体宽高、旋转与手脚位置，不能只让重心轨迹连续。
- 手明明抓住器物，缩小后却看成身体的一部分：拉开接触手、配件与主体的轮廓，近景和手机尺寸都要能认出接触关系。
