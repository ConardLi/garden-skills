# 白板手绘解说（whiteboard-explainer）

> 图在观众眼前画出来，箭头与标注把一句解释变成看得懂的关系。
> 参照（只学语法）：RSA Animate 的全局白板、MinutePhysics 的分段手绘讲解。

## 本质 / 不是什么

- 本质：绘制顺序就是解释顺序。笔先画什么、在哪里停、何时连接旧图，都应该帮助观众理解内容。
- 与一笔线描的区别：允许抬笔和多个独立图形，重点在解释关系；与黑板外观的区别：光有纸纹和手写字体还不够，必须让关系随绘制逐步成立。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 跟得上的笔尖 | 笔尖停在当前笔迹末端，转场时抬起 | 工序、概念介绍 |
| 分笔画图 | 轮廓、细节、标注依解释顺序出现 | 原理、流程 |
| 因果箭头 | 箭杆先到对象，箭头最后确定方向 | 因果、决策 |
| 一张关系地图 | 前面的图留在板上，最终能看出全局 | 系统、知识网络 |
| 局部圈注 | 圈出已存在的细节，再添加解释 | 纠错、重点 |
| 擦改痕迹 | 只擦掉需要修订的地方，保留上下文 | 迭代、方案对比 |
| 少量语义色 | 一种色持续指代同一角色或状态 | 分类、责任关系 |
| 画外空间 | 镜头跟随讲解移到板上另一处 | 长流程、发现 |
| 手绘比喻 | 简单物体承担一个明确的概念 | 面向新手的解释 |
| 总览停留 | 拉远后给观众时间复述关系 | 总结、回顾 |

规则：每支挑 2–3 个，至少一个不在俗套里。图形服务主题；一只手并不能自动让内容变成白板解说。

## 这个风格最俗的版本

- 画面：白底、库存手掌、灯泡和齿轮，所有字由同一个横扫遮罩揭开；画完就清屏。
- 声音：轻快尤克里里一直循环，笔声从头响到尾。
- brief 写明保留哪些经典信号、改变哪些默认做法。可以从已有图上的矛盾开始，也可以边回顾边修订。

## 适配

- 用途：原理讲解、操作说明、方案介绍、课程片段和过程回顾。
- 内容：需要建立关系或解释变化，能够删成少量图形与短标注的主题。
- 密集逐字字幕、精确产品截图和纯材质宣传应选择其他主风格。口播长片须按真实音频规划，而非按固定画图速度凑时长。

## 技术路线

- SVG 或 Canvas 组织有明确顺序的独立路径。SVG 的路径长度接口、Paper.js 的曲线工具可辅助测长；笔迹与笔尖必须查询同一份弧长进度。
- Rough.js 可探索稳定的手绘边缘，但其双线效果需要控制；不能每帧重新随机生成一遍。
- 有真实书写需求时，使用可核对的字形笔画数据或手工整理的中心线。字体轮廓、横扫遮罩、锯齿遮罩均不能当成真实笔顺。
- 大白板在世界坐标中完整排好，镜头只改变观察位置。分纸页则明确切页，不混成空间跳变。
- 通常 `--subframes 1–2`；过多采样会把快速笔尖抹成灰影。背景纹理固定，通常不用额外 `--grain`。

## 材质与渲染

- 工艺依据：记号笔接触白板、沿路径移动、抬起后换位置。依次处理笔迹、笔身、接触阴影和抬笔动作。
- 线宽随压力缓慢变化，已经画出的线保持不动。回描只用于强调，不给每一根线都套双描边。
- 记号笔的端点饱满，转角略圆；铅笔变体可以更细、更灰，整片的主体和箭头采用同一工具。
- 白板保留轻微灰暖色，字与线要有充足对比。纸面变体可加固定纸纹，避免用重污渍削弱阅读。
- 手或笔应从真实的连接位置出发，不能突然换手；闲置时抬起退场，不悬在结论上方挡字。

## 配色

示例只看思路，不照抄。

- 清爽白板：底 `#FAFAF5` / 墨 `#26343A` / 重点 `#D66B42`。
- 冷白教学：底 `#F4F8F7` / 墨 `#203E4A` / 关系色 `#2C807E`。
- 纸上笔记：底 `#F1E9D8` / 墨 `#343435` / 圈注 `#B64844`。

从主题选一两种语义色，先固定含义再分配图形；不要按镜头更换含义。大片填色应给轮廓和箭头留出空间。

## 字体

英文短标注可用自托管 OFL 的 Caveat、Patrick Hand；中文可用有清楚授权的手写字体，或思源黑体作为排好的旁注。后者整词出现，不伪装成笔写。字形必须正常；图比正文多，最终总览也要能读到主要结论。

## 运动

- 绘制速度按路径长度和理解难度安排；新概念的识别部位稍慢，重复细节更快。
- 每个笔画结束后留出抬笔和转移时间。箭头的绘制方向与语义方向一致。
- 讲解中的停留用于阅读、比较和回想。镜头在画笔工作时少动，移动后再画下一组，减少双重追踪负担。
- 擦除要留下明确的局部变化依据；不要在同一镜头凭空替换整幅图。

## 画面怎么活

- 以静为主：已画内容是观众的记忆支点。
- 讲到某处时，可补一根下划线或一个小圈；强调结束后也静止。
- 只有内容需要时，让图中的活动对象沿已经画好的关系移动。不能用全板线条抖动冒充手绘感。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 固定近景画一组 | 集中理解一个对象 | 原理、定义 |
| 短平移到邻近图 | 从原因走到结果 | 流程、因果 |
| 沿连接线回访 | 新证据改变旧理解 | 反馈、修订 |
| 拉远后停住 | 看见完整关系 | 系统、总结 |
| 明确换纸页 | 开始新的论点 | 章节式讲解 |

## 声音调色板

第 1 档可用轻木音、稀疏拨弦、短促的记号笔摩擦；拟音只在接触时出现，停笔必须停止。真实笔声可用第 2 档配授权采样。人声是解说版的主角，配乐降低旋律密度，笔声避开关键词。

律动可选轻切分、一问一答或自由分句；不必用持续四拍推进。有口播时，笔迹进度、镜头与声音事件按真实语音时间安排，并通过带声预览核对。

## 原生手法

- 一笔画到旧图，把前后概念连成因果链：适合过程讲解（经典）。
- 擦掉局部假设，其余关系保留，让新结果自然成立：适合纠错。
- 先画局部，拉远后看见它在更大关系中的位置：适合系统认知。
- 用第二种颜色回到旧图，只补上缺少的连接：适合反馈和协作。

## 变化空间

- 结构：从问题逐步搭图；从全图定位误解；对照两种方案并修订其中一处。
- 开场：先画关键矛盾；圈出已画图里的异常；从一个未完成的连接出发。
- 结尾：保留可复述的总览；回到开头补上答案；留下与后续章节相连的空位。

## 坑

- 笔尖和笔迹各自缓动，出现“画在前面、笔追在后面”：两者查询同一条路径和同一个进度。
- 笔尖在长距离换笔处瞬移：明确划分接触、抬笔、移动，不能把转移也画成线。
- 汉字由扫光出现却标为手写：改用真实笔画数据，或明确作为排版旁注。
- 全局图没有提前排好：先验证总览，再决定局部镜头；避免末尾拉远后主文字太小。
- 只画图标，没有发生关系变化：把箭头、比较、修订纳入叙事，而非最后一次性补齐。
- 镜头和笔同时快跑：分配注意力，关键绘制期间固定镜头。
- 一个 SVG 路径包含多个移动命令，采样后却连成一条折线：按独立子路径分笔；每个移动命令都要重新判断是否接触纸面。
- 快速抬笔被多子帧采样合成两只半透明的手：先检查转移时间，再降低子帧数；笔迹边缘与手部拖影应分别取舍。
- 用整段画图时间播放笔声：从实际接触区间生成声音事件，短暂停笔与换位置时也要留空。
