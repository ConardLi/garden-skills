# 彩色玻璃镶嵌（stained-glass）

> 彩色玻璃被深色金属条分隔，背后的光穿过色片，把图案投到周围空间。
> 参照（只学语法）：铅条镶嵌彩窗、几何玻璃屏风、彩色玻璃上的烧绘工艺。不照搬具体宗教图像、建筑彩窗和现代艺术作品。
> 借鉴方向：[lemo-opuscar 的 Stained Glass](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/stained-glass/STYLE.md)，按本库结构重新整理，技术实现由 Agent 按主题探索。

## 本质 / 不是什么

- 本质：**分片的玻璃过滤光，金属骨架组织图像**。玻璃片有边界、厚度和不同透光程度；亮度来自背光，金属条依然暗实，投出的彩光与片的位置相互对应。
- 不是：`glass-material` 的透明产品陈列，也不是把平面插画切成多边形。前者重折射与反射，这里重色片、接缝和透光形成的图案。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 铅条骨架 | 深色条带包住每块玻璃，交汇处有节点 | 连接、结构、工艺 |
| 透光色片 | 相邻色片亮度与透光程度不同 | 多样性、情绪、品牌 |
| 波纹玻璃 | 片内有固定的细波纹，透光略不均匀 | 手工、自然、质感 |
| 彩光落地 | 窗面图案化成拉长或柔化的地面色斑 | 空间、时间、氛围 |
| 几何花窗 | 圆、瓣或重复单元围绕结构排列 | 汇聚、循环、仪式 |
| 不规则拼片 | 形状顺着人物、植物或抽象轮廓分块 | 叙事、生命、变化 |
| 烧绘暗线 | 玻璃表面有少量深色细节与遮光笔触 | 表情、局部纹理、文化 |
| 侧光金属边 | 窄小高光显出接缝的厚度 | 工艺、局部特写 |
| 单片补位 | 缺口中的色片归位，图案与投影同时补全 | 修复、协作、完成 |
| 背光换时 | 光源角度缓变，色片亮暗和落地光一起变化 | 时间、季节、情绪 |

规则：

- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选。
- 分片沿内容结构设计，主轮廓可以由多片组成。圆形花窗、宗教场景和宝石色都只是选择。

## 这个风格最俗的版本

- 画面：教堂玫瑰窗居中，彩虹色铺满每片玻璃，金光从后射出，碎片旋转拼成 Logo。
- 声音：管风琴加合唱，拼一片就响一声玻璃铃，最后长混响收尾。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么保留经典版。可用横向屏风、少色植物图案或局部修补，让主题决定空间。

## 适配

- 用途：文化与工艺宣传、品牌情绪片、Logo 演绎、片头、空间氛围循环。
- 内容：光、时间、修复、共同组成整体，也适合现代几何品牌。
- 不适合：密集图表、快速界面演示，或需要色彩精确不受照明影响的产品展示。

## 技术路线

- **平面彩窗**：SVG、Canvas 可处理分片、接缝和透光层；Paper.js 可辅助裁切与共享边界，避免相邻片留出不受控的缝。
- **空间彩窗**：需要侧视厚度、背光和地面时，可探索 Three.js 的透射材质、灯光与投影。真实彩色透射和焦散成本较高，可按镜头需要选择自定义着色或经过校准的投影近似。
- **光与纹理**：PixiJS 或 WebGL 适合片内波纹、局部亮度和遮罩。投到地面的图案应由同一组色片与光向推导，不能另画一团无关的彩色光。
- 固定玻璃纹理种子，任意时刻独立恢复光源与片的位置。`--dpr` 先保证接缝平顺；`--subframes` 用于缓慢光影和移动片，`--grain` 保持轻或关闭。

以上是实现方向，不要求物理级焦散，也不指定材质参数和渲染引擎组合。

## 材质与渲染

- 工艺依据：玻璃按图案切割，边缘嵌进金属槽，接点焊接，形成能透光的面。分片应有可拼合的边界，金属条有连续的支撑关系。
- 玻璃片是刚体。片内波纹跟着片走，形状不会像液体呼吸；变形转场应明确借用切割或重组的图形手法。
- 背光越强，透光片越亮，但烧绘暗线与金属仍压住光。深色玻璃不会在所有光向下都自动变成霓虹。
- 边缘可有轻微厚度与反光，金属接缝比玻璃更实、更暗；不能把每片做成鼓起的宝石。
- 彩光随光向改变位置、拉伸和柔软程度，被金属条挡住的地方留下较暗分隔。主体同样由色片和接缝组成，不能另贴一张平滑 Logo。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 深蓝与琥珀：环境 `#18262D` / 玻璃 `#326E9C`、`#D99A43` / 铅条 `#252629`。
- 植物屏风：环境 `#E9E1CC` / 玻璃 `#6B8A69`、`#B9634F` / 铅条 `#393B35`。
- 烟粉与冷白：环境 `#262C37` / 玻璃 `#BC8796`、`#B8D3DC` / 铅条 `#25252D`。
- 推导：从主题取两三组玻璃色，拉开透光后的明度，而非给每片换一种色相。底色承担室内环境，金属保留深度；强调片在数量和面积上都要克制。

## 字体

英文可选 Cormorant Garamond、Marcellus，现代几何主题可用 Jost；中文用思源宋体或思源黑体，自托管 OFL 字体。标题放在相对完整的暗区或浅区，辅助字不跨越多块明暗差大的玻璃。复杂字形不强行切成镶嵌片。

## 运动

- 玻璃片移动时保持硬质重量，围绕明确边缘翻转或沿槽位归位，轻微减速后停稳；不做软弹簧挤压。
- 以光变化为主的镜头让窗体保持稳定，亮度与投影共同缓慢移动。避免玻璃自己发光、地面却没有响应。
- 进场可由遮光撤去、缺片补齐或视角转正完成；退场可转向投影、闭合光源或移到相邻窗格。

## 画面怎么活

- 固定窗体前，彩光在地面缓慢挪动，移动量只够让观众感到光向变化。
- 片内纹理不游动，允许环境中的柔暗影从背后经过，引起局部亮度变化。
- 工艺特写里，一段金属接缝随观察角度出现窄反光；阅读落版时以静为主。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 正面固定，背光变化 | 图案与时间 | 品牌、氛围、循环 |
| 小角度侧移到正面 | 厚度与透光 | 工艺、材质 |
| 从窗面移到落地彩光 | 对空间的影响 | 建筑、情绪、时间 |
| 从接缝局部拉远 | 多片如何成为整体 | 协作、修复、Logo |

## 声音调色板

第 1 档可用柔和风琴铺底、少量钢片或卡林巴音、低密度敲击。需要真实玻璃触碰、室内混响或弦乐时，用第 2 档 Tone.js 配合授权采样。玻璃接合只给轻而短的硬质声，别把每次运动都做成破碎声；有口播时收短混响尾音。

律动与和声（举例，不止这些）：缓慢的持续和声、温柔的分解音型，或清晰轻巧的几何节奏。神圣感适合部分主题，现代空间也可干净、明亮而世俗。

## 原生手法

- 色片沿接缝拼合，完整图案透出光：适合共同组成整体（经典）。
- 缺片归位，窗面与地面投影同时补全：适合修复、协作和完成。
- 镜头落到彩光上，让投影的轮廓成为下一段图形：适合空间和主题之间转场。
- 保留金属骨架，只替换其中一组玻璃色：适合季节、版本和状态对比。
- 背光掠过烧绘细节，先前藏在暗处的线条出现：适合发现、文化和局部揭示。

## 变化空间

- 结构：追随一束光观察同一面窗；围绕缺片讲修复；按窗格展开几个相关主题。
- 开场：先看地面彩光；近看一处金属接点；完整彩窗在暗处逐渐透亮。
- 结尾：停在可读的整面图案；只留一块有意义的色片发亮；投影延伸出画框接下一章。

## 坑

- 玻璃像软糖：减少鼓包和弹性，先保持平面与刚性边界。
- 线条只是覆盖在多边形上：建立共享接缝与节点，避免双边线和断口。
- 一直发光却没有背光方向：确定光源位置，让窗与环境共同响应。
- 投影和色片不对应：共用图案与运动来源，检查缺片、遮挡和光向变化。
- 彩虹色和高饱和铺满全屏：限制色组，保留深片与安静区域。
- 宗教母题与内容无关：从主题设计分片形状，不把教堂当必选背景。
- 小字跨过高反差接缝：另留题签区，或在正文出现时降低背后细节。
- 金属条在尖角处偏离色片：不能把直线切割边统一平滑成曲线；玻璃轮廓、接缝和投影遮光边应沿同一边界。
- 彩光像贴在地上的硬质插画：保留色片对应关系，再按投射距离控制软边与亮度；先抽看背光打开前后的帧，确认光源变化确实传到地面。
