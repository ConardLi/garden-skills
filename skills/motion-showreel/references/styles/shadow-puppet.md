# 透光皮影（shadow-puppet）

> 染色皮革与镂空纹样在背光幕布上显出形象，关节和操纵杆让人物以清楚的侧影表演。
> 参照（只学语法）：中国皮影的刻制、染色与操纵、幕布背光舞台、关节偶的表演方式。不照搬具体流派的整套人物、传统戏目造型或唱段。

## 本质 / 不是什么

- 本质：**用透光材料、铰接动作和幕面投影完成表演**。皮革色层过滤背光，镂空处透出幕色，重叠部位更暗；人物的转动从肩、肘、髋等连接处发生。
- 不是：`paper-cut` 的纸层厚度与投影，也不是纯黑剪影动画。这里强调染色皮革透光、关节操纵与幕面距离，纸张纤维和立体书翻页不承担核心表现。

## 辨识信号：每支片子挑 2–3 个

| 信号 | 长什么样 | 适合的主题 |
|---|---|---|
| 透光染色 | 皮革透出温暖色彩，厚处与叠层更暗 | 文化、人物、工艺 |
| 镂空花纹 | 小孔、细缝与纹样透出幕布亮色 | 材料、身份、细节 |
| 侧身造型 | 侧脸与侧向动作构成清楚的剪影 | 对话、行进、表演 |
| 关节铰接 | 肢体围绕圆点转动，分片形状保持刚性 | 动作、协作、器物 |
| 操纵杆 | 细杆连接手部或身体，传递动作方向 | 幕后、制作、控制 |
| 叠片加深 | 手臂经过身体前后时色彩变深 | 层次、接触、表演 |
| 离幕虚化 | 远离幕布的片变软，靠近后变清楚 | 出场、退场、情绪 |
| 幕面织纹 | 微弱纤维与不完全均匀的背光 | 舞台、手作、空间 |
| 横向舞台调度 | 人物从两侧进入，动作在同一台口展开 | 相遇、对话、旅程 |
| 场景片换景 | 树、门、建筑等平面片移动，改变地点 | 故事、章节、空间 |

规则：

- 每支挑 2–3 个，至少一个不在下面「最俗的版本」里；信号从主题里选。
- 操纵杆可以按观看角度显露或隐藏，关节逻辑始终成立。现代人物与器物也可以制成皮影，不必默认传统戏曲角色。

## 这个风格最俗的版本

- 画面：泛黄幕布、红黑武将、戏台花边，两个人挥刀交手，最后一张红印收尾。
- 声音：锣鼓不停，每抬一下手都配一下锣，背景加来源不明的戏曲唱腔。
- brief 的 style 一栏写明翻掉了哪几条，或者为什么保留经典版。可从日常相遇、器物合作或一只皮影的制作过程入手。

## 适配

- 用途：文化工艺宣传、故事向品牌片、原理讲解、Logo 演绎、舞台式循环。
- 内容：人物关系、传承、控制与协作，以及适合侧向动作表达的情节。
- 不适合：自由环绕的三维动作、精细面部演技、密集 UI 操作和长篇图表说明。

## 技术路线

- **分片与镂空**：SVG、Canvas 都适合封闭轮廓与孔洞；Paper.js 可辅助纹样求交和裁切。每个活动肢体作为独立刚性片，明确连接点。
- **透光合成**：Canvas 或 PixiJS 可探索色片透光、叠层变暗与幕布纹理。合成方法先用两片相叠的小样验证，不能直接透明叠加到发白。
- **距离与投影**：固定舞台可用分层模糊和缩放近似；需要展示灯、偶和幕的位置时，再探索 Three.js 的平面几何与投影。近似效果也应遵守一致的光源关系。
- 关节、操纵杆端点、离幕距离和背光按时间独立还原，皮纹与幕纹固定种子。`--dpr` 先保镂空孔与细杆；`--subframes` 从轻，`--grain` 不叠加到遮住纹样。

以上是候选路线，不规定骨架结构、透光着色和投影实现。

## 材质与渲染

- 工艺依据：皮料刮薄、刻出孔纹、染色后分片连接，借背光在幕上显形。先处理厚薄、孔洞与关节，再加旧物痕迹。
- 镂空处显示幕布本色，染色片保留透光感；较厚的轮廓、接头和多层重叠更暗，不应都用一样的不透明度。
- 孔洞与细桥的宽度要经得住最终尺寸，不能刻到整个主体碎成难以辨认的噪点。纹样顺着服装和器物结构排列。
- 肢体片保持刚性，关节转动可略有操纵的停顿。弯腰、挥手由分片和连接表达，不能像橡皮管一样任意拉长。
- 明确灯、偶、幕的相对位置。离幕导致的大小与虚实变化应成组发生；幕纹固定在幕上，皮纹随偶移动。

## 配色

下面的色值是示例，看思路，不要原样照抄。

- 暖幕与朱色：幕 `#EAD4A5` / 皮色 `#A34A32` / 辅色 `#8D743D` / 厚边 `#3E3027`。
- 象牙与青绿：幕 `#EDE3C9` / 皮色 `#4D7B6A` / 辅色 `#BA794A` / 厚边 `#303F38`。
- 暗台琥珀：环境 `#2C2926` / 亮幕 `#D7BB83` / 皮色 `#874D3E` / 强调 `#B39348`。
- 推导：先定幕色与灯色，再选穿过背光后仍可区分的皮料色组。品牌色可用于主要分片，叠层要自然变深；避免高饱和发光边把皮革变成霓虹。

## 字体

中文展示可用思源宋体，辅助用思源黑体；英文可用 Alegreya 或 Libre Baskerville，自托管 OFL 字体。标题可作为独立题签或幕外说明，长字幕保持平稳清晰。镂空字只适合短字与大字号，不把细小正文切成花纹。

## 运动

- 先确定身体的支撑和手中物件，再安排关节角度。动作有提、送、停的操纵感，不能每个关节同时自由摇摆。
- 人物多沿横向舞台移动，转身可借换面、遮挡或短暂退幕后完成；不强行把侧脸平面转成三维头部。
- 进场可以从幕边、虚影或场景片后出现；退场也沿舞台或离幕方向完成。击打和接触短促，阅读与反应留停顿。

## 画面怎么活

- 停住时，手或操纵杆末端可有极小的余摆，身体主姿态稳定。
- 背光允许缓慢、低幅变化，幅度不影响字幕和人物识别，不能整屏频闪。
- 一片旗、枝叶或灯穗做稀疏摆动，其他布景安静；幕布纹理不游走。

## 镜头语法

| 镜头运动 | 表达什么 | 适合哪类内容 |
|---|---|---|
| 正面固定的舞台全景 | 动作与人物关系 | 相遇、协作、故事 |
| 轻推到手与关节 | 如何操纵、如何接触 | 工艺、控制、细节 |
| 沿幕面横移 | 地点与人物行进 | 旅程、章节 |
| 从幕前转到幕侧的有限揭示 | 表演背后的材料与人力 | 制作、传承、幕后 |

## 声音调色板

第 1 档可用手鼓、木质敲击、短拨弦与很轻的皮料摩擦噪声。需要真实锣鼓、传统器乐或操纵拟音时，用第 2 档 Tone.js 配合授权采样，音色与题材相符。唱腔不作为默认装饰；有口播时只在动作落点和段落间保留少量打击。

律动与和声（举例，不止这些）：有问答与停顿的打击节奏、安静的拨弦叙事，或简洁的现代环境音乐。剧烈动作与日常场景可以有不同密度，避免整片持续敲锣。

## 原生手法

- 人物贴近幕布，由虚影变成清楚的镂空色片：适合出场和首次揭示（经典）。
- 两片重叠变暗，再分开露出各自纹样：适合相遇、分工与关系变化。
- 操纵杆的动作传到手中物件，再带动另一个主体：适合控制、协作和连锁。
- 场景片横向换入，人物继续沿同一台口行动：适合旅程和章节交接。
- 镜头转到幕侧露出分片与灯，再回幕前看完整形象：适合工艺和幕后解释。

## 变化空间

- 结构：围绕两者的一次相遇；跟随一个角色换景；先看表演，再逐层揭示制作方式。
- 开场：只有一只手的虚影；幕上已有场景，角色从遮挡后出现；一块未连接的皮片被提起。
- 结尾：人物退到幕边留下布景；动作停在关系明确的姿态；背光收弱，最后保留一个可读轮廓。

## 坑

- 全部做成纯黑剪影：检查透光色、孔洞和叠层是否可见。
- 叠片越叠越亮：重新校准透射与遮光关系，不用加亮混合代替背光。
- 肢体像软胶拉伸：保持分片刚性，动作从关节发生。
- 杆端与手脱开：操纵杆连接点随关节一同求取。
- 镂空过细，压缩后只剩噪点：减少纹样密度，优先保住轮廓。
- 远离幕布只加模糊，尺度关系却矛盾：按同一光源位置处理大小与虚实。
- 幕纹跟人物一起移动：把幕、皮料、灯光分开处理。
- 传统符号与故事无关：从当前主题设计主体，不用戏曲服饰替代角色塑造。
