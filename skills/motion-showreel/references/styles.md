# 风格：长什么样、怎么动、什么声音

每种风格只写**不变的规则**：材质、配色、字体、运动、镜头语法、声音调色板、原生手法和坑。**不写故事、镜头顺序和具体分镜**，这些从用户的主题和 `formats.md` 的用途里来。换一个主题时，风格规则保留，内容全部重新设计，不要把上一支片子换个文案再交一次。

只读选中的那一种。用户想要的风格不在这里时，就按最后的「自定义风格」模板现写一份规则，放进 brief。

| 风格 | 一句话 | 主要技术 |
|---|---|---|
| 1 瑞士编辑 | 网格、一种字体、一个信号色，运动像印刷机一样精确 | Canvas / DOM |
| 2 极简界面 | 浅色、干净、弹簧手感的产品界面动效 | DOM / SVG / Canvas |
| 3 像素 CRT | 小画布整数放大、步进动画、显像管质感 | Canvas + WebGL 后期 |
| 4 3D 材质 | 在空间里运动的镜头，玻璃、金属和光 | Three.js |
| 5 生成抽象 | 由规则生成的图形、阵列、场，周期运动 | Canvas / WebGL 着色器 |
| 6 手绘笔触 | 彩铅、水彩、墨线，像一张张手画出来 | p5.js + p5.brush / Canvas |

## 1 瑞士编辑

- **本质**：二维平面设计在网格上运动。纸色背景、黑色字和色块，再加**唯一一个**饱和的信号色。元素贴网格、动作落在拍上、不回弹。整体严谨，只允许一个例外元素，它就是主角。
- **不是**：发布会 keynote（没有渐变、发光、设备渲染图），也不是歌词视频（字不飞、不转、不弹）。
- **材质**：12 栏网格、大面积留白、平面色块；没有阴影、渐变和粒子，不加颗粒。
- **配色**：纸 `#EAE9E5` / 墨 `#111` / 一个信号色（红 `#E30613`、橙 `#FF5A00`、群青 `#1F3FFF`、绿 `#16C172` 选一个）。只有主角带信号色。
- **字体**：全片一个 OFL 新怪诞体家族（Archivo、Schibsted Grotesk、Instrument Sans 等），用多个字重；左对齐、右侧不齐；巨大的数字配很小的注释。
- **运动**：用 `snap` 缓动（硬起步、长滑行），**不用会回弹的弹簧**（阻尼 ≥ 0.9）；元素按网格跳位；切换卡在重拍上。
- **镜头**：二维相机，平移和缩放都对齐网格；整片可以基本不动机位，靠版式变化制造运动。
- **声音**：干净的电子乐、精确的 tick 网格、短促的 click；少用混响。
- **原生手法**：网格从一个点长出来；巨大的数字其实是一个小版式的局部（拉远揭示）；色块擦除换版。
- **坑**：栏太细会像图表；元素没贴网格就显得随意；第二个强调色会毁掉系统。

## 2 极简界面

- **本质**：真实感的产品界面在干净的舞台上动：浅暖灰背景、白卡片、细描边，所有变化都有弹簧手感。
- **不是**：赛博 HUD、深色加霓虹、拟物化。
- **材质**：圆角卡片、细描边（1.5–3px）、柔和的投影（只给浮起的那一层）；可以有一层很淡的颗粒。
- **配色**：背景 `#EFEDE8`–`#F5F4F1`，墨 `#111`，灰阶 3 级，外加一个品牌强调色。
- **字体**：一款干净的界面字体（Geist、Instrument Sans、Inter Display 的替代品）加一款等宽字体。
- **运动**：UI 档弹簧 `{3.6, 0.8}` 管指示条和开关，`{2.4, 0.75}` 管容器；内容切换时带一下短暂的模糊；光标驱动状态变化。快速形变可以加 `--subframes 4`。
- **镜头**：跟着当前状态缩放，让它占满画面；轻微的倾斜回正。
- **声音**：界面音效在前（click、tick、pop、swipe），音乐退后（拨弦、柔和的鼓）。
- **原生手法**：形变链；前沿和后沿拉伸；光标拖过头时元素被拉长。
- **坑**：被缩放的文字变糊；新旧内容叠在一起；投影太重显得廉价。

## 3 像素 CRT

- **本质**：所有内容画在很小的逻辑画布上（160×90、128×96、320×180），再整数倍放大；姿势按每秒 8–12 张步进，特效每帧都动；最上层盖一层显像管质感。
- **不是**：缩小了的矢量图形，也不是把抗锯齿图片糊成像素风。
- **材质**：关闭平滑，坐标取整，不用渐变和 `shadowBlur`；CRT 后期包括弧面、扫描线、荧光点和色差（recipes.md 第 12 节）。
- **配色**：固定 16–32 色调色板（夜空深蓝紫、暖色角色、3–4 个高亮色），每个像素都来自调色板。
- **字体**：像素字体，或者在逻辑画布上用 ≥ 18px 的字按 alpha 阈值转成硬边。
- **运动**：`stepped(t, 10)` 量化角色姿势；**镜头和光照保持每帧平滑**；用状态机组织动作（待机 → 蓄力 → 释放 → 收招）。
- **镜头**：整像素平移；撞击时震屏 1–2 个逻辑像素。
- **声音**：芯片音乐（方波旋律、方波或三角波低音、噪声鼓），`blip`、`glitch`。
- **原生手法**：一个年代一个分辨率的媒介切换；像素块溶解转场。
- **坑**：中文糊成一团；镜头也步进了；着色器没生效（先渲一帧确认）。

## 4 3D 材质

- **本质**：一个主体（物体、文字、阵列）悬在空间里，材质和光是主角，镜头缓慢而精确地运动。
- **不是**：白底商品图，也不是线框 HUD。
- **材质**：`MeshPhysicalMaterial`（玻璃：transmission、ior、thickness；金属：低粗糙度加环境光）；面光源加低强度环境贴图；后期景深，bloom 只给发光体；`--dpr 2` 用来抗锯齿。
- **配色**：中性世界（黑、灰、高光白），只有光带颜色，限一个色系。
- **字体**：超细或超粗的宽字距无衬线体，标题放在上三分之一。
- **运动**：所有状态在 `render(t)` 里设置，不用 `Clock`；爆炸图拉开时 ease-out，合拢时用很短的 ease-in 卡在重拍上。
- **镜头**：缓慢环绕、推近、微距转焦、低角度仰拍；切点只放在拍点上；镜头一直在漂，不锁死。
- **声音**：sub drone、boom、颗粒感 shimmer、慢 riser；撞击用 boom。
- **原生手法**：爆炸图；平面字挤出成 3D；几万个实例组成一个形状；光在物体内部流动。
- **坑**：代码搭的模型只适合风格化，要像真实产品就需要用户提供模型；软件渲染非常慢。

## 5 生成抽象

- **本质**：由规则生成的图形（阵列、流场、波、SDF），相位错开形成涌动；常常没有文字。
- **不是**：随机粒子爆炸、屏保。
- **材质**：线条和点为主，或者全屏着色器；颗粒可选。
- **配色**：单色、双色或一组渐近色（OKLab 插值）；浅色或深色都可以，但要有明确的明度结构。
- **运动**：周期函数（整数倍频率），相位 = 序号 × 常数；在这种风格里匀速旋转是对的。
- **镜头**：常常固定，或者用很慢的缩放和旋转。
- **声音**：氛围铺底、慢拨弦、shimmer，或者无声。
- **原生手法**：对称阵列在一拍内翻转；场线汇聚成文字或 logo。
- **坑**：用了逐帧累积的模拟（会破坏确定性和循环）；元素太多、帧时间暴涨。

## 6 手绘笔触

- **本质**：像一张张手画出来的：笔触有方向、粗细、纸纹，画面每秒只换 8–12 次，镜头仍然平滑。
- **不是**：矢量图加一层纸纹滤镜。
- **材质**：p5.brush（彩铅、水彩、蜡笔）或者 Canvas 自己写笔触；纸张底纹；笔触的随机种子用 `floor(t * 12)`。
- **配色**：颜料的有限调色板，留出纸色。
- **字体**：手写体或有手作感的衬线体；字也可以由笔触写出来。
- **运动**：步进 12fps；形体变化有手绘的「抖动」（逐帧轻微变形）。
- **镜头**：慢推、横移视差（纸片分层）。
- **声音**：原声乐器（拨弦、钢片琴），纸张和铅笔的拟音。
- **原生手法**：一笔画出下一镜；墨或水彩晕开成转场。
- **坑**：笔刷非常慢，先测单帧耗时再定时长；随机种子没按帧固定会导致闪烁。

## 自定义风格

用户要的风格不在上面时，把下面这份规则写进 brief（参照 lemo-opuscar 风格库的组织方式）：

```markdown
风格：<名字>（参照：<1–2 个作品或流派，只学语法>）
本质 / 不是什么：…
材质与渲染：…（用什么技术，质感层怎么做）
配色：…（hex，强调色只给谁）
字体：…
运动：…（缓动或弹簧档位，要不要步进）
镜头语法：…（哪些运动表达什么）
声音调色板：…（配器和音效的材质）
原生手法：…（只有这种媒介能做到的转场或记忆点）
坑：…
```
